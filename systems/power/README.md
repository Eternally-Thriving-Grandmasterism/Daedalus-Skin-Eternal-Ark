# Power Generation & Distribution

## Primary Source
The same D–³He fusion systems used for propulsion (or dedicated continuous fusion reactors) supply the majority of electrical and thermal power.

## Key Requirements
- Habitat lighting, life support, computing, manufacturing, and magnetic shielding coils
- High reliability with multiple independent reactor clusters
- Efficient waste heat rejection via large radiator arrays

## Architecture Principles
- Modular, hot-swappable power modules
- Multiple independent power buses with automatic isolation
- Superconducting transmission where practical to reduce losses
- Energy storage (capacitors / advanced batteries) for pulse loads and emergency
